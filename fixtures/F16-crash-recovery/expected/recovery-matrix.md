# F16 recovery matrix

Seven injection points, each kills the build with SIGKILL. After restart:

| Injection point | DB state | Manifest state | Expected recovery |
|---|---|---|---|
| `after-rows-before-commit` | old committed only (transaction rolled back) | old | normal; old index readable |
| `after-commit-before-flip` | old committed + pending | old | discard pending; stale; old index readable |
| `after-flip-before-manifest` | new committed, manifest old | old | rewrite manifest from DB (`manifest-repaired`) |
| `manifest-tmp-written` | new committed, manifest old | old | rewrite manifest from DB (`manifest-repaired`) |
| `after-manifest-before-surface` | new committed + new manifest, surface old | new | `stale-surface`; next `update` rebuilds |
| `after-surface-before-workspace` | new committed + new manifest + new surface, workspace old | new | workspace is derived; rebuild on next run |
| `workspace-before-cleanup` | complete build; tmp may remain | new | cleanup tmp; normal |

The assertions are generated by `packages/core/test/recovery.test.ts`; this
file is documentation, not an oracle produced by the tool itself.
