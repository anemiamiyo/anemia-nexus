# 0. 修订说明

## 0.1 本版修订的性质

v1.24 是**约束性修订**，不是功能版本。产品定位、技术选型主链（SCIP + TypeScript Compiler API + @vue/language-core + SQLite）、阶段划分（Phase 00–07）全部保留。本版只做四类改动：

1. **把"已声明"改成"已定义"**：凡是原文只给结论、不给判定条件的地方，补上判定条件、数据来源和失败行为。
2. **把"承诺"改成"有限范围的承诺"**：完整性、零漏检、身份稳定、性能预算，全部加上适用范围或校准前置条件。
3. **把"隐含执行"改成"显式授权"**：配置文件、自定义命令、第三方插件、项目脚本，逐项划出权限边界。
4. **把"章节自治"改成"全局一致"**：新增第 23 章登记跨章节冲突及其消解结论，禁止不同章节对同一概念给出两种口径。
