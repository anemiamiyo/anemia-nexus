## 3. 已发现的文档/生态漂移（Phase 00 需在报告中说明）

1. npm 上的 `scip-typescript` 不是 Sourcegraph 官方包，当前仅有 `0.0.1-security`（安全占位包）。官方包为 **`@sourcegraph/scip-typescript`**。
2. `@sourcegraph/scip-typescript@0.6.2` 依赖 TypeScript 6 且要求 Node ≥22.23.4，与本项目 TS 5.x / Node 22.16 下限冲突；Phase 00 选用 **0.4.0**（依赖 TypeScript ^5.6.2）进行验证，版本差异本身纳入 G1 风险记录。
3. npm 上不存在 `@sourcegraph/scip`；0.4.0 在包内提供 protobuf 解析模块 `dist/src/scip.js`。Phase 00 直接使用该模块解析 `index.scip`，并把“官方解析包缺失”列为生态风险。
4. 上述均属**实现层选型细节**，不改变 4.3 的映射策略与验收口径；若 0.4.0 无法满足 G1，按 20.6 提交架构问题报告。
